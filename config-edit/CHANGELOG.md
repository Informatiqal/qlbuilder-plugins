# Changelog

All notable changes to this project will be documented in this file.

## [1.1.0] - 2026-10-26

- new `config` command - `list`. Print names for all available environments

## [1.0.0] - 2026-10-26

- initial version
- available commands
    - `config` - show help for `config` command
    - `config add` - add brand new environment
    - `config remove` - remove existing environment
    - `config update` - update existing environment (env name or env property value)

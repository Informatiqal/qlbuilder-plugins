# qlbuilder Plugins

Repo containing community `qlBuilder` plugins.

## Docs

Follow the [official documentation](https://docs.informatiqal.com/qlBuilder/plugins/developing/) to get more understanding on what are `qlBuilder` plugins and how to write them.

## Plugins list

- [data model viewer](./data-model-viewer/README.md) - export Qlik's app data model viewer as `png` image
- [config editor](./config-edit/README.md) - manage the home folder config (`.qlbuilder.yaml`) - add/remove/update environments and their properties
